# Case Study Website

A standalone case-study website for the Dwell Construction campaign (and future campaigns).

## Setup
1. Clone this repository.
2. Run \`npm install\` to install dependencies (Astro, Tailwind CSS).
3. Run \`npm run dev\` to start the development server.

## Architecture
- Framework: Astro
- Styling: Tailwind CSS
- The main Dwell Construction case study page is located at \`src/pages/case-studies/dwell-construction.astro\`.
- All CSS variables for colors and themes are defined in \`src/styles/global.css\`.

## Assumptions
- "KANISHK PRABHAT" logo text links back to the root of the case study site (or can be changed to the main portfolio).
- Placeholder images and videos have been used via \`public/images/\` placeholders or dummy CSS blocks.
- Interactions are limited to hover states and basic transitions.
